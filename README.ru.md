**Plyrty** — это легковесная, современная обёртка для HTML5 видеоплеера, предназначенная для беспроблемного стриминга. Она предоставляет единый интерфейс для воспроизведения потоков **HLS** (`.m3u8`) и **DASH** (`.mpd`), автоматически обрабатывая зависимости библиотек.

В отличие от стандартных обёрток, Plyrty оснащён алгоритмом **Smart Auto-Quality**, который проверяет пропускную способность сети перед переключением качества, предотвращая прерывания воспроизведения и избыточные перезагрузки потока.

 

## ✨ Ключевые возможности

- 🎥 **Поддержка нескольких форматов:** Встроенная поддержка **HLS.js** и **Dash.js**. Плеер автоматически определяет тип потока и загружает необходимые библиотеки из CDN, если они отсутствуют.
- 🧠 **Умное автоматическое качество:**
  - **Проверка пропускной способности:** проактивно тестирует скорость сети перед переключением качества в режиме "Авто".
  - **Логика без перезагрузки:** интеллектуально проверяет, совпадает ли вычисленное "Авто" качество с текущим, предотвращая ненужные сбросы потока (проверка `currentHeight === newHeight`).
  - **Память:** запоминает последнее выбранное автокачество (`lastAutoHeight`) для мгновенного применения при будущих сеансах или переключениях.
- 📺 **Современный интерфейс:**
  - Кастомные элементы управления с **Phosphor Icons**.
  - Меню настроек для качества и скорости воспроизведения.
  - Режимы "Картинка в картинке" (PiP) и полноэкранный.
  - Интерактивный ползунок громкости и отображение времени.
  - Умная иконка громкости: показывает разные иконки для mute (<code>ph-speaker-x</code>), нулевой громкости (<code>ph-speaker-none</code>), низкой громкости (<code>ph-speaker-low</code>) и высокой громкости (<code>ph-speaker-high</code>).
- 📡 **Готовность к Chromecast:** Встроенная кнопка трансляции и интеграция с Google Cast Framework.
- 🎨 **Темизация:** Полностью настраиваемый через CSS-переменные.
- 🛠 **Удобство для разработчиков:** Подробная система логирования с цветовой кодировкой для отладки.

## 🚀 Установка

Просто подключите скрипт в свой проект. Plyrty автоматически обнаружит элементы `<video>` с классом `plyrty` или вы можете инициализировать его вручную.

```
<!-- Подключение скрипта Plyrty -->
<script src="path/to/plyrty.js"></script>

<!-- Добавление CSS (или позвольте скрипту обработать стили, если они встроены) -->
<link rel="stylesheet" href="path/to/plyrty.css">
```

## 📖 Использование

### Базовый метод (автоматически)
Добавьте класс `plyrty` к вашему тегу video. Скрипт автоматически инициализирует его при `DOMContentLoaded`.

```
<div class="plyrty-root">
    <video class="plyrty" controls>
        <source src="https://example.com/stream.mpd" type="application/dash+xml">
    </video>
</div>
```

### Ручная инициализация
Вы можете программно установить источник для любого видеоэлемента, используя глобальный API.

```
// Выберите видеоэлемент по селектору или ссылке
plyrtySetSource('#myVideo', 'https://example.com/video.m3u8', 'application/x-mpegurl')
    .then(() => {
        console.log('Видео успешно загружено!');
    })
    .catch(err => {
        console.error('Не удалось загрузить видео:', err);
    });
```

## ⚙️ Конфигурация

### Плейлисты и эпизоды
Plyrty поддерживает расширенные конфигурации, такие как плейлисты. Вы можете передавать опции при инициализации (если используете внутренний `initPlayer` напрямую) или структурировать HTML для поддержки этого.

### Темизация
Вы можете настроить внешний вид плеера, переопределяя CSS-переменные в вашем файле стилей или передавая объект `theme` в опциях.

```
.plyrty-root {
    --primary-color: #ff0000;
    --control-bar-bg: rgba(0, 0, 0, 0.8);
}
```

### Оптимизация для мобильных устройств

Plyrty предоставляет улучшенный мобильный опыт с интуитивно понятными сенсорными управлениями:

- **Любое нажатие**: Показывает интерфейс управления плеером при первом нажатии
- **Последующие одиночные нажатия**: Показывают интерфейс и ждут 300мс для проверки дабл тапа перед переключением воспроизведения/паузы
- **Двойное нажатие на левой стороне**: Перемотка назад на 10 секунд (без показа интерфейса)
- **Двойное нажатие на правой стороне**: Перемотка вперед на 10 секунд (без показа интерфейса)
- **Нажатия на элементы управления**: Взаимодействуют с элементами управления нормально (не вызывают паузу/воспроизведение)
- **Нажатия на элементы меню**: Взаимодействуют с элементами меню нормально (не вызывают паузу/воспроизведение)
- **Увеличенные сенсорные зоны**: Улучшенная доступность на маленьких экранах

Плеер автоматически адаптируется к различным размерам экрана и ориентациям для оптимального просмотра.

### Глобальная стилизация

Plyrty позволяет глобально настраивать внешний вид плеера через CSS-переменные. Вы можете переопределить любую из переменных по умолчанию, чтобы соответствовать дизайну вашего сайта:

```
/* Пример: Глобальная настройка плеера */
.plyrty-root {
    --plyrty-primary: #ff6b35;
    --plyrty-background: #1a1a1a;
    --plyrty-text: #ffffff;
    --plyrty-accent: #ff6b35;
}
```

Доступные CSS-переменные включают цвета, размеры и анимации, которые влияют на весь внешний вид плеера.

## 🧠 Как работает Smart Auto-Quality

Стандартные плееры часто переключают качество вслепую, основываясь на состоянии буфера, что приводит к эффекту "йо-йо". Plyrty улучшает это следующим образом:

1.  **Проверка:** Когда выбран режим "Авто", плеер загружает небольшие фрагменты видеосегментов для расчёта пропускной способности в реальном времени.
2.  **Верификация:** Перед переключением он сравнивает новое кандидатное качество с текущим активным.
3.  **Стабильность:** Если `currentHeight` равен новой целевой высоте, команда переключения отменяется, обеспечивая плавное продолжение воспроизведения без перезагрузки медиа-движка.

## ♿ Доступность и управление

- Горячие клавиши управляют только тем плеером, который находится в фокусе (или открыт в полноэкранном режиме), поэтому несколько плееров на одной странице не конфликтуют.
- Для кнопок и интерактивных элементов добавлены заметные индикаторы клавиатурного фокуса.
- Учитывается системная настройка `prefers-reduced-motion`.
- На мобильных экранах увеличена удобная область перемотки и учтены safe-area отступы.
